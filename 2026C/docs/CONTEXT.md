# 微电网调度术语

本文件统一问题二、问题三中预报、购电计划与实际执行的用语。符号、公式及模型假设分别见 [symbols.md](symbols.md)、[Q2.md](Q2.md) 和 [Q3.md](Q3.md)。

## 数据与信息

**光伏预报批次**：在某一发布时间提供的一组光伏功率预测，具有各自的目标时刻。同一目标时刻在不同批次中的预测可以不同。
_避免_：不注明发布时间的“当天光伏预测”。

**预报覆盖范围**：一批预报所描述的目标时间范围。它与本次决定购买哪些时段的电量是两个不同概念。
_避免_：用“预测未来24小时”直接表示“提交未来24小时购电计划”。

**可用实测**：决策时已经观测到的实际负载、实际光伏等运行数据。离线附件中尚未发生的记录不属于当前可用实测。
_避免_：用“已读取全年附件”表示“已经知道全年实际数据”。

**冷启动先验**：尚无历史实测样本时，用于生成初始预测的已知参考曲线。先验不是已经发生的实测。
_避免_：将附件1参考曲线称为附件2的历史样本。

**历史负载基线**：仅依据当前日期以前已经获得的历史负载，形成的目标日各时段参考负载曲线。它与当天已发生实测所产生的日内修正分别记录。
_避免_：将历史基线和日内修正统称为无法区分来源的“更新后负载”。

**当日负载偏差修正**：利用当天已完成时段相对历史基线的偏差，对尚未发生时段负载预测作出的调整。
_避免_：把当天部分实测直接当成当天完整历史样本。

## 计划与执行

**初始购电计划**：当天0点提交的各供电时段计划购电量，是后续描述日内调整时需要保留的原始版本。
_避免_：用“购电量”同时指代初始计划与实际全部外网购电。

**候选调度方案**：依据某次可用信息，在预测情景下计算的购电量、充放电量和储电量轨迹。候选量只有经过相应提交或执行环节，才成为购电承诺或实际动作。
_避免_：把预测情景下的充放电轨迹称为实际充放电结果。

**正式购电调整**：在允许的决策时刻，对当天尚未执行的购电承诺作出的有效变更。它与变更费用何时结算、按哪个版本比较是不同的概念。
_避免_：把“允许多次更新购电承诺”等同于“每次必须独立收取一笔费用”。

**调整后购电量**：某次调整形成的供电时段购电总量。它与相对基准增加或减少的差额分别记录。
_避免_：在同一字段内混用调整后总量与增减购差额。

**有效购电量**：某供电时段实际执行时，依据已经生效的计划及调整应当提供的非紧急购电量。问题三的调整费用按它相对0点初始计划的最终差额结算一次。
_避免_：把初始计划与各次调整后的计划全量相加。

**减购退费**：在供电前正式减少初始计划电量时，返还该减少部分的原计划电费。问题三同时对该部分收取50%的违约费，净返还为原时段电费的50%。
_避免_：将计划电量已生效但最终未利用也称为可退费的减购。

**模板显示时间**：结果模板用于标示供电区间的时间标签，通过约定映射对应实际调度区间。
_避免_：用模板显示时间界定实测何时可用或移动实际储电量状态。

**紧急购电量**：实际供电出现负载缺口时用于补足该缺口的外网购电量，与事先提交的计划购电或日内增购分别记录。
_避免_：用“临时买电”混指正式日内增购与紧急购电。

**实际储电量**：储能设备在某个时间边界的内部电量，由已经执行的充放电动作形成。它与预测情景下的储电量轨迹分别记录。
_避免_：用计划日末储电量代替下一天的实际初始储电量。
