本文件按项目约定汇总建模文档中的符号。

## 时间相关

| 符号                           | 含义                                                  | 单位或范围                               |
| ---------------------------- | --------------------------------------------------- | ----------------------------------- |
| $N$                          | 一天的调度时段数                                            | 144                                 |
| $\Delta t$                   | 单个调度时段长度                                            | $1/6$ h                             |
| $t$                          | 调度时段或状态边界索引                                         | 时段为 $1,\ldots,N$；状态边界为 $0,\ldots,N$ |
| $\tau_t$                     | 第 $t$ 个时间边界，自当天 0:00 起累计                            | h，$\tau_t=t\Delta t$                |
| $I_t$                        | 第 $t$ 个调度区间                                         | $[\tau_{t-1},\tau_t)$               |
| $p_t$                        | 第 $t$ 时段外网购电电价                                      | 元/kWh                               |
| $L_t$                        | 第 $t$ 时段小区负载功率                                      | kW                                  |
| $\widehat P_t^{\mathrm{pv}}$ | 第 $t$ 时段光伏预测功率；帽号表示预测值                              | kW                                  |
| $\ell_t$                     | 第 $t$ 时段负载电量，$L_t\Delta t$                          | kWh                                 |
| $v_t$                        | 第 $t$ 时段可用光伏电量，$\widehat P_t^{\mathrm{pv}}\Delta t$ | kWh                                 |

## 储能参数

| 符号                        | 含义                     | 单位或取值                             |
| ------------------------- | ---------------------- | --------------------------------- |
| $E_{\mathrm{rated}}$      | 储能额定最大容量               | 12000 kWh                         |
| $E_{\min}$                | 运行储电量下限                | 1200 kWh                          |
| $E_{\max}$                | 运行储电量上限                | 10800 kWh                         |
| $E_{\mathrm{init}}$       | 当天 0:00 的已知内部储电量       | kWh；问题一按题给初值及逐日日末回归条件取 6000       |
| $P_{\max}^{\mathrm{ch}}$  | 母线侧最大充电功率              | 5000 kW                           |
| $P_{\max}^{\mathrm{dis}}$ | 母线侧最大放电功率              | 5000 kW                           |
| $\eta_{\mathrm{ch}}$      | 充电效率                   | 无量纲，0.9                           |
| $\eta_{\mathrm{dis}}$     | 放电效率                   | 无量纲，0.9                           |

## 通用的决策变量与状态

| 符号    | 含义                       | 单位或范围                             |
| ----- | ------------------------ | --------------------------------- |
| $g_t$ | 第 $t$ 时段外网计划购电量          | kWh，非负                            |
| $c_t$ | 第 $t$ 时段储能设备的充电量         | kWh，非负                            |
| $d_t$ | 第 $t$ 时段储能设备的放电量         | kWh，非负                            |
| $r_t$ | 第 $t$ 时段未利用的可用光伏电量       | kWh，$0\le r_t\le v_t$             |
| $e_t$ | 时间边界 $\tau_t$ 的电池内部储电量   | kWh，$E_{\min}\le e_t\le E_{\max}$ |
| $u_t$ | 储能运行模式变量，$u_t\in\{0,1\}$ | $u_t=1$ 时允许充电，$u_t=0$ 时允许放电。      |

## 问题一的输出

| 符号                  | 含义                                       | 单位或范围        |
| ------------------- | ---------------------------------------- | ------------ |
| $J$                 | 全天购电费用，模型最小化目标                           | 元            |
| $W_{\mathrm{loss}}$ | 全天储能充、放电造成的电量损耗                          | kWh          |
| $G_{\mathrm{day}}$  | 最优方案的全天外网购电量，$\sum_{t=1}^{N}g_t^{\star}$ | kWh          |

## 问题二新增变量与输出

| 符号                        | 含义                                         | 单位或范围                 |
| ------------------------- | ------------------------------------------ | --------------------- |
| $d$                       | 日期索引                                       | $d=1,\ldots,334$      |
| $g_{d,t}^{\mathrm{plan}}$ | 第 $d$ 天在 0:00 确定的第 $t$ 时段计划购电量             | kWh，非负                |
| $\widehat{\ell}_{d,t}$    | 第 $d$ 天第 $t$ 时段的预测小区负载电量                   | kWh，非负                |
| $\widehat{v}_{d,t}$       | 第 $d$ 天第 $t$ 时段的预测可用光伏电量                   | kWh，非负                |
| $\ell_{d,t}$              | 第 $d$ 天第 $t$ 时段的实际小区负载电量                   | kWh，非负                |
| $v_{d,t}$                 | 第 $d$ 天第 $t$ 时段的实际可用光伏电量                   | kWh，非负                |
| $h_{d,t}$                 | 第 $d$ 天第 $t$ 时段的紧急购电量                      | kWh，非负；按 $5p_t$ 计费    |
| $w_{d,t}$                 | 第 $d$ 天第 $t$ 时段未利用的计划购电量                   | kWh，非负；仅在允许弃置计划购电量时使用 |
| $n_{d,t}$                 | 第 $d$ 天第 $t$ 时段的实际净负荷，$\ell_{d,t}-v_{d,t}$ | kWh                   |
| $\mathcal F_{d-1}$        | 制定第 $d$ 天计划时可用的历史信息集                       | 截至第 $d-1$ 天结束时已知的信息   |
