# 国赛 C 题建模手备战指南

> 目标：能够把赛题翻译成明确的数学问题，选择有依据的方法，设计验证，并向队友解释模型为什么可信。
>
> 本指南以 2019—2025 年本科 C 题为训练背景，规则核对日期为 **2026-09-08**。学习优先级、训练时长和验收标准是建议，不是官方评分细则，也不意味着必须掌握全部方法才能参赛。

配套文档：[C 题解题流程与建模方法](./01_C题解题流程与建模方法.md) · [编程手备战指南](./03_C题编程手备战指南.md)

**推荐阅读顺序：** 先用第 1—3 节确定学习边界，按第 4—9 节补方法，再照第 10—13 节练真题、练协作、做验收。

## 1. 建模手不是“算法名称检索员”

### 1.1 核心职责

建模手应当负责六件事：

1. **定义问题：** 谁在什么时点，用什么信息，做什么判断或决策？
2. **理解数据：** 一行是什么，变量是什么含义，数据能支持什么结论？
3. **建立模型：** 变量、假设、关系、目标、约束如何表达？
4. **选择方法：** 为什么先用这个基线，什么证据支持升级？
5. **设计验证：** 哪种实验能发现模型不适用，如何评估误差与风险？
6. **解释结果：** 数值对现实问题意味着什么，哪些结论不能说？

不合格的交接是：“你用随机森林跑一下，再用遗传算法优化。”

合格的交接是：“在每周订货前，用此前已经观察到的供货信息估计供应分布；订货量为决策变量，保持统一产出当量下的库存平衡；用过去若干滚动窗口回测库存不足率和成本，与固定比例订货策略比较。”

### 1.2 建模手需要会编程吗

**需要基础编程能力，但不必和编程手一样熟练。** 最低要求：

- 能读懂数据表、基本统计图和模型输出。
- 能写或修改短脚本，检查均值、单位换算和小规模算例。
- 能读懂目标函数、特征工程、验证切分和约束实现。
- 能发现“论文写了一个模型，程序实际算的是另一个”的不一致。

即使主要用 Excel、MATLAB 或统计软件，也应记录可复现步骤。完全不看数据、只负责写公式，会使模型脱离现实。

### 1.3 如何判断一种方法真的学会了

对任何模型，都回答以下七问：

1. 它解决什么问题，输入与输出是什么？
2. 核心假设是什么，数据为何大致满足？
3. 关键公式和参数有什么含义？
4. 与简单基线相比，增加了什么能力？
5. 如何求解，复杂度和失败方式是什么？
6. 怎样检验，什么证据说明它不适合？
7. 如何向论文手用一段话和一张表解释？

能背公式但答不出这些问题，通常还不具备比赛中的使用能力。

## 2. 学习优先级：先构建够用的主干

### 2.1 P0：优先熟练，构成参赛基础

| 模块 | 必学内容 | 应达到的程度 |
|---|---|---|
| 问题抽象 | 粒度、变量、参数、目标、约束、信息时点 | 能逐问写任务卡和数学模型 |
| 基础数学 | 线性代数、微积分、概率统计 | 能理解矩阵模型、优化、估计与不确定性 |
| 数据理解 | 描述统计、缺失/异常、业务口径 | 不把错误数据处理交给算法“自动解决” |
| 回归与推断 | 线性回归、相关、区间、基本检验 | 能区分拟合、解释、显著性与因果 |
| 分类与验证 | 逻辑回归、决策树、交叉验证、指标 | 能处理重复对象、时间依赖和不平衡 |
| 简单预测 | 均值/同期基线、趋势、季节性 | 能做符合信息时点的滚动回测 |
| 运筹优化 | 线性规划、0-1 变量、MILP、库存平衡 | 能把常见经营规则写成约束 |
| 可靠性 | 基线、敏感性、情景、约束审计 | 能发现“高分但无效”的结果 |
| 科学表达 | 符号、假设依据、论证、引用 | 能把模型来龙去脉写清楚 |

### 2.2 P1：根据训练题补齐

- 聚类、PCA、AHP/熵权/TOPSIS 等评价方法。
- 随机森林、梯度提升、SVM、正则化。
- 指数平滑、ARIMA、带外生变量的时间预测。
- 动态规划、基础非线性规划。
- Bootstrap、随机优化、鲁棒思想、机会约束、CVaR。
- 重复测量、混合效应、成分数据、删失与达标时间。
- 排队模型与离散事件仿真。

这里的 P1 不是“永远不重要”。若训练 2025 C，重复测量和达标时间就应提升为当前题目的必学内容；若训练 2024 C，多期整数规划和不确定性就是主线。

### 2.3 P2：有明确需要才投入

- 深度神经网络、LSTM、Transformer。
- 遗传、粒子群、模拟退火等多种启发式的复杂组合。
- 高级因果推断、高维贝叶斯和复杂随机过程。
- 与当前任务无关的偏微分方程、图像深度学习等专项技术。

这些方法不是没用，而是入门时常常投入大、验证难，收益不如把 P0 做扎实。能用线性/整数规划清楚求解的问题，不必先换成随机搜索。

## 3. 数学基础学到什么程度

### 3.1 线性代数：理解模型结构和数值稳定性

重点内容：

- 向量、矩阵、维度与矩阵乘法。
- 线性方程组、秩、线性相关。
- 最小二乘、正交投影。
- 特征值、特征向量、SVD 和 PCA 的直观意义。
- 正定矩阵、条件数和病态问题的基本概念。

要能理解：

$$
y=X\beta+\varepsilon,
\qquad
\widehat\beta=\arg\min_\beta\|y-X\beta\|_2^2.
$$

其中每一行对应什么样本、每一列对应什么特征。要知道强共线性会使系数不稳定；标准化不是解决一切问题；实际计算通常不应手工求逆实现最小二乘。

**训练任务：** 用两列高度相关的特征拟合回归，观察系数在轻微扰动后如何变化，再比较 Ridge 正则化。交付：系数表、验证误差、对不稳定原因的解释。

### 3.2 微积分与优化：把“最好”写成可求解的目标

重点内容：

- 一元和多元函数、导数、偏导、梯度。
- 极值、约束、边界解。
- 凸集和凸函数的直观认识。
- 拉格朗日乘子与 KKT 条件的基本含义。
- 不可微点、分段函数与线性化。

需要能看懂：为什么 $\min(\text{产量},\text{需求})$ 会使收入分段；为什么最优解可能在边界；为什么非线性算法收敛不自动证明全局最优。

**训练任务：** 写出固定价格下“销售收入−采购成本”的补货利润函数，用图像解释最优进货量；再加入损耗和滞销折价，检查拐点如何变化。

### 3.3 概率统计：理解数据能够支持多强的结论

重点内容：

- 条件概率、独立性、全概率和贝叶斯公式。
- 常见分布的应用条件：二项、泊松、正态等。
- 期望、方差、协方差、相关。
- 抽样、估计、置信区间与假设检验。
- 大数定律和中心极限定理的使用边界。
- 样本量、抽样偏差、缺失机制与测量误差。

必须理解：

- 大量重复记录不一定意味着大量独立样本。
- “未拒绝原假设”不是“证明原假设成立”。
- 置信区间不是个体未来观测值的预测区间。
- 一般有 $f(E[X])\ne E[f(X)]$，因此把随机参数都换成均值，未必得到合理的平均收益。

**训练任务：** 在含偏态和极端值的小数据上比较均值、中位数与重采样区间，说明不同统计量回答的问题。

## 4. 数据分析与统计推断：不要只会画图和看 p 值

### 4.1 描述统计与探索分析

至少会做：

- 均值、中位数、标准差、四分位数、分位数、变异系数。
- 分组统计、交叉表、分层比较。
- 散点图、箱线图、分布图、时间图。
- 异常值和缺失模式检查。

注意变异系数在均值接近 0 时不稳定；对不同单位变量不能直接比较方差大小来判断业务重要性。

每张图后要写一句有内容的话，例如：“某类别的分布右偏且上四分位区间较宽，均值不足以代表典型日需求，后续比较中位数和分位数预测。”不要只写“结果如图所示”。

### 4.2 相关分析

| 方法 | 适合的问题 | 需要知道的限制 |
|---|---|---|
| Pearson 相关 | 线性关系强弱 | 对异常值敏感；推断所需条件与计算相关系数本身不同 |
| Spearman 相关 | 单调关系、秩次关系 | 不等于发现所有非线性关系，也不证明因果 |
| 分层相关/回归调整 | 比较条件控制后的关系 | 仍可能存在未测混杂和模型误设 |

特别训练两个反例：

1. 两个时间序列因共同趋势而高度相关，去除趋势后关系明显减弱。
2. 总体相关与分组内相关方向不同，认识混杂与辛普森悖论。

对于成分比例，所有变量受总和约束影响；原始相关矩阵中的负相关可能部分来自闭合效应，不能直接解释为化学排斥或替代机制。

### 4.3 假设检验与效应量

优先学习：

- 两组连续数据：合适的 t 检验或非参数方法。
- 多组比较：方差分析或合适替代方法。
- 类别变量关系：卡方独立性检验；稀疏列联表考虑精确检验等方法。
- 回归系数检验与置信区间。
- 多重比较的基本控制方法。

选择方法前明确：独立还是配对？对象是否重复？样本量是否足够？要检验均值、分布还是其他量？

不要把所有非参数检验都解释为“比较中位数”，其结论还依赖具体检验和分布条件。也不要机械规定“先正态性检验，p 大于 0.05 就证明正态”。

**练习：2022 C 的风化关系分析。**

1. 明确统计单位是文物还是采样点。
2. 建立风化与类型、纹饰、颜色的列联表。
3. 检查稀疏格与缺失情况，选择适当方法。
4. 报告样本量、效应量/关联程度与不确定性。
5. 说明多个检验和样本结构的限制。

### 4.4 线性回归与广义线性模型

至少掌握：

$$
y_i=\beta_0+\sum_{j=1}^{p}\beta_jx_{ij}+\varepsilon_i.
$$

学习重点：

- 参数估计、截距和斜率含义。
- 非线性项和交互项何时有业务意义。
- 残差图、异方差、自相关、异常影响点和共线性。
- 训练拟合与泛化误差的区别。
- Ridge/Lasso 的作用及标准化要求。
- 因变量类型与模型匹配：连续量、比例、计数、二分类不能不加区别。

“某系数为负”应解释为在模型所控制变量及假设下的条件关系，不能自动表述为因果影响。

### 4.5 重复测量与混合效应：2025 C 的重要准备

可从随机截距模型理解个体差异：

$$
y_{jt}=\beta_0+\beta_1\,\text{孕周}_{jt}
+\beta_2\,\text{BMI}_{jt}+u_j+\varepsilon_{jt}.
$$

$j$ 表示孕妇，$t$ 表示检测时点；$u_j$ 表示个体层面的差异。它不是唯一选择，但能帮助理解为什么同一人的多次检测不能视为完全独立。

需要会比较：

- 忽略重复结构的简单模型；
- 合理聚合后的模型；
- 混合效应、广义估计方程或适当稳健推断。

选择取决于问题要解释什么、预测新对象还是同一对象、数据量是否支持。聚合会丢失时间信息，也不是万能修复。

## 5. 预测与分类：重心是验证设计

### 5.1 一条可靠的建模链

```text
定义目标和使用时点
→ 选择可用特征
→ 设计分组/时间划分
→ 建立朴素基线
→ 在训练折内预处理和调参
→ 验证比较
→ 锁定模型和阈值
→ 最终评估
→ 输出解释与局限
```

学会这条链，比同时记住十种分类器更重要。预处理和特征筛选必须服从训练/测试隔离；官方文档对这一点有明确说明。[技1]

### 5.2 回归预测应该掌握什么

推荐顺序：

1. 均值、中位数、上一期/同期值等基线。
2. 线性回归、Ridge/Lasso。
3. 决策树、随机森林或一种梯度提升方法。
4. 如存在真实时间结构，再使用适合的时序方法。

会选择 MAE、RMSE 等指标，并能解释其业务含义。RMSE 对大误差更敏感；MAE 更直接反映平均绝对偏差；R² 可以补充，但不是唯一依据，测试 R² 也可能为负。

### 5.3 分类至少学好逻辑回归和决策树

逻辑回归：

$$
P(Y=1\mid x)=\frac{1}{1+\exp[-(\beta_0+\beta^Tx)]}.
$$

需要理解：模型估计概率，分类标签还需要阈值；默认 0.5 不是所有场景的最优阈值。

决策树需要理解：分裂规则、树深、叶节点样本量、过拟合和剪枝思想。小样本上，一棵浅树可能比复杂黑箱更容易验证和解释。

再掌握一种较强的树集成方法作为对照即可，不必比赛中同时尝试全部流行库。

### 5.4 类别不平衡与决策成本

若异常只有少数，全部预测“正常”也可能有很高准确率。

应当报告：

- 混淆矩阵：TP、FP、TN、FN。
- 精确率、召回率、F1。
- 与类别比例相对应的基线。
- ROC-AUC 与 PR 曲线/平均精确率的适用含义。
- 若概率要进入优化，检查校准，而不只看排序能力。

在误报和漏报代价不同的情境，可用

$$
\text{经验损失}=C_{FN}\,FN+C_{FP}\,FP
$$

比较阈值。但成本从哪里来、是否只是情景假设，需要说明；不能凭空设一个代价比后把所得阈值称为临床标准。

过采样、欠采样或 SMOTE 若使用，必须局限在训练折内。对小样本稀有异常，简单类别权重与保守模型常更值得先尝试。

### 5.5 数据划分要与泛化目标一致

- 要预测新企业：按企业划分。
- 要预测新孕妇：按孕妇划分。
- 要预测同一门店下周：按日期划分。
- 同时推广到新对象和未来时段：设计同时满足这两个目标的验证方案。

同一对象多次记录随机分到训练和测试中，可能产生“记住对象”的虚高成绩。分组切分器只能保证组不重叠，不能自动证明其他信息无泄漏。[技2]

多条记录的对象还会得到更大权重。必须明确指标是在检测记录层面还是对象层面计算，必要时同时报告二者。

### 5.6 解释工具的边界

特征重要性、置换重要性、SHAP 等可以辅助解释预测模型，但：

- 相关特征之间的重要性分配可能不稳定。
- 重要性不等于因果贡献。
- 重要性不提供传统意义上的显著性证明。
- 解释方法自身也依赖背景数据和建模设定。

## 6. 时间预测、聚类与综合评价

### 6.1 时间序列：先掌握朴素方法与回测

必学：时间粒度、趋势、季节性、滞后、滚动统计、自相关、平稳性的概念。

建议模型顺序：

1. 上一期值、上周同日值。
2. 移动平均、指数平滑。
3. 带日历和滞后特征的回归。
4. 在结构支持时尝试 ARIMA 或其他合适模型。

关键是严格模拟业务：在截止日一次性预测未来 7 天，和每天获得真实销量后预测下一天，是两种不同任务。不能用测试期前几天的真实销量辅助“截止日时做出的七天预测”。

2023 C 可以练习：按品类构造日销量，识别缺失营业日与零销量，滚动回测一周预测，比较常规日和异常日的误差。

### 6.2 聚类：回答“如何分组”，不是假装已知真值

至少掌握层次聚类和 K-means 的基本原理，知道：

- 距离、尺度和变量选择会影响分组。
- K-means 偏好相对紧凑的欧氏空间簇，不适合所有结构。
- 聚类数需要结合内部指标、稳定性和业务意义。
- 结果可能随随机初始化、异常值和标准化改变。

2022 C 的亚类划分适合训练“先定义有意义的成分空间，再聚类，再解释和扰动验证”。如果没有真实亚类标签，就不要把轮廓系数改名为准确率。

### 6.3 PCA：降维不等于找出业务重要性

需要理解：PCA 找解释方差较大的线性方向，主成分符号可整体翻转；解释方差大不一定表示对目标预测重要，也不必然符合业务价值。

使用前考虑尺度；预测任务中的 PCA 只能在训练折内拟合。若本来只有少量易解释变量，不一定需要降维。

### 6.4 AHP、熵权、TOPSIS：知道何时不使用

| 方法 | 主要作用 | 应会的检查 |
|---|---|---|
| AHP | 表达层次结构和主观偏好 | 判断矩阵依据、互反性、一致性、权重敏感性 |
| 熵权法 | 根据样本指标差异给权重 | 指标方向、非负化、零值、常数列、异常值影响 |
| TOPSIS | 按距离理想解评价排序 | 标准化、权重、距离定义和排名稳定性 |

AHP 常见的一致性比例经验阈值，不等于判断矩阵符合现实的证明；熵权偏重差异较大的指标，不证明该指标更有业务价值；TOPSIS 得分也不是概率。

学习时不只背步骤，还要做三个对照：

1. 与等权排序比较。
2. 去掉一个高度重复指标。
3. 在合理范围内调整权重，检查前若干名是否稳定。

若题目已有明确收益和资源限制，优先考虑直接优化，而不是把一切转成综合评分。

## 7. 运筹优化：建模手最值得补强的能力之一

### 7.1 线性规划

基本形式：

$$
\max c^Tx,\qquad Ax\le b,\quad x\ge0.
$$

要会把以下问题写成模型：采购配比、运输分配、生产计划、预算配置。

必须理解：可行域、最优解、不可行、无界、对偶或影子价格的基本含义。影子价格的经济解释通常依赖当前最优结构及允许扰动范围，不能无限外推。

### 7.2 0-1 变量与混合整数规划

常见“现实语言 → 约束”练习：

| 现实语言 | 常用表达方式 |
|---|---|
| 是否选供应商/商品 | $z_i\in\{0,1\}$ |
| 选中才允许有数量 | $0\le x_i\le M_i z_i$ |
| 选中后至少达到最小量 | $m_i z_i\le x_i\le M_i z_i$ |
| 最多选 K 个 | $\sum_i z_i\le K$ |
| 二者不能同时选 | $z_i+z_j\le1$ |
| 选 A 必须选 B | $z_A\le z_B$ |
| 两种方案必须二选一 | $z_A+z_B=1$ |

$M_i$ 应由容量、需求或其他上界推导，不能习惯性写成 $10^9$。过大的 Big-M 会使数值与求解效率变差。

### 7.3 多期模型与守恒关系

库存模型的核心之一是：

$$
I_t=I_{t-1}+R_t-d_t.
$$

这里所有量必须用相同单位；如果不同原材料有不同转化率，应换成统一产出当量，或者分别记录原料库存与生产消耗。运输损耗应在对应环节扣除，不能漏算或重复扣算。

需要会明确：

- 期初与期末库存。
- 订货提前期和到货时点。
- 库存下限是硬约束还是“尽量满足”的软目标。
- 各期容量与累计容量。
- 决策能否随着新信息更新。

2021 C 非常适合训练“订货—供货—转运—接收—库存—产出”的全链条，不能把订货直接当作确定到货。

### 7.4 种植约束的建模训练

2024 C 可按层次逐步建立：

1. 单年、单季、固定收益的面积分配。
2. 增加地块适种和不同地块季数。
3. 增加滞销浪费与折价销售两种收入机制。
4. 加入跨季/跨年重茬和 2023 年历史状态。
5. 处理三年豆类覆盖。
6. 加入管理上的最小面积和不分散要求，并说明具体量化假设。
7. 最后加入不确定性、替代互补和相关性。

“每块地三年豆类面积累计大于地块面积”是一种可能的聚合近似，不自动保证每部分土地轮到豆类。若采用细分地块、位置一致的轮作单元或轮作序列，应明确如何保证真实覆盖。

### 7.5 非线性规划、动态规划和启发式

**非线性规划：** 适合连续非线性关系；了解初值、局部最优、梯度、边界和约束。存在整数与非线性时，先尝试合理离散化、线性化或分解，不轻率把所有复杂度一次引入。

**动态规划：** 会定义阶段、状态、动作、转移和边界条件。例如多期库存、有限状态下的策略选择。要估计状态空间，防止“维数灾难”。

**启发式：** 在确有复杂离散结构、标准求解困难时可考虑，但必须设计可行性保持/修复、停止条件、重复运行与基线。算法运行多次得到相似结果，不构成全局最优证明。

### 7.6 优化模型的验收标准

- 小规模问题与枚举/手算一致。
- 所有硬约束逐条通过，且考虑数值容差。
- 目标函数用独立公式重新计算。
- 整数、上下界、物料或面积平衡正确。
- 如实记录最优/可行/不可行/超时等状态。
- 有与基线的对比，并说明模型最优不等于现实绝对最优。

## 8. 不确定性、风险和特殊数据结构

### 8.1 敏感性、Bootstrap、蒙特卡洛分别解决什么

- **敏感性分析：** 假设或参数变化后，结论是否改变。
- **Bootstrap：** 在合适抽样与依赖假设下，估计统计量的不确定性。
- **蒙特卡洛：** 根据设定分布生成情景，传播不确定性。

模拟不是验证的替代品。由同一个错误模型生成数据，再证明该模型能解释这些数据，不能证明其符合现实。

训练时至少记录：随机种子、分布、参数来源、相关结构、模拟次数和结果稳定性。对有重复对象的数据按对象重采样；对时间序列考虑块重采样等保留依赖的方法。

### 8.2 从确定性优化升级到风险决策

推荐学习顺序：

1. 固定参数求一个可行基线。
2. 在多个情景下评价同一个方案。
3. 调整方案以兼顾平均表现和坏情景。
4. 有必要时再建立随机、鲁棒或机会约束模型。

几种思想的区别：

| 方法 | 关注点 | 主要代价/前提 |
|---|---|---|
| 期望收益优化 | 平均收益 | 依赖情景概率，不直接限制尾部风险 |
| 鲁棒优化 | 给定不确定集合内的保守表现 | 集合过宽可能过于保守 |
| 机会约束 | 约束满足概率达到要求 | 概率估计与分布假设需可靠 |
| CVaR 风险控制 | 不利尾部的平均损失 | 置信水平与风险权重需说明依据 |

对损失 $L_\omega$，场景权重 $w_\omega$，常见 CVaR 场景表达为：

$$
\operatorname{CVaR}_{\alpha}(L)
=\min_{\eta,u}\left[\eta+\frac{1}{1-\alpha}\sum_\omega w_\omega u_\omega\right],
\quad u_\omega\ge L_\omega-\eta,\quad u_\omega\ge0.
$$

这里 $0<\alpha<1$，权重非负且和为 1。要先定义损失是负利润、目标收益缺口还是其他量，不能把收益尾部和损失尾部写反。风险参数是决策偏好，缺少客观依据时应做多档比较。

### 8.3 防止“预知未来”的优化

先做的决策必须在尚未区分的情景间相同，这通常称为**非预见性/非前瞻性要求**。

例如：当年播种前并不知道实际收成和价格，不能按每个情景各选一套播种面积，然后把平均最优利润当作可实现收益。可以把这种完美信息结果当参考上界，再与实际可执行策略比较。

### 8.4 成分数据：2022 C 的专项准备

成分比例带有总和约束。需要了解：

- 闭合效应为何能制造或改变相关结构。
- 原始百分比、合理标准化和对数比分析各自的意义。
- CLR/ILR 的基本思想，CLR 坐标总和为 0，不能不加处理地当成满秩独立特征。
- 对数比不能直接处理真零；未检出、真零和检测限需要区分。
- 微小值替换会影响结果，应说明依据并进行敏感性分析。

不要求入门就深入全部成分数据理论，但必须知道普通相关和欧氏距离在这里存在特殊风险。

### 8.5 达标时间与删失：2025 C 的专项准备

先定义研究的是“观测值第一次达标”还是“潜在平均浓度/持续状态第一次达标”。有检测误差、浓度波动时，二者不同。

在合适的潜在变化假设下：

- 前一次未达标、后一次达标，真实达标时间可能位于两次之间。
- 第一次观察已经达标，可能存在左删失。
- 最后一次观察仍未达标，可能存在右删失。

不能把所有未观察到达标的人删除，也不能把末次检测时间当真实达标时间。若潜在浓度非单调，还需讨论首次跨越与再次跌落，不能未经说明直接套区间结论。

可考虑浓度—孕周关系模型、达标概率模型、生存/区间删失方法等不同路线。选择哪种路线，取决于数据支持、假设可信度和比赛时间，不是要求全用。

BMI 分组与时点决策还需要：

- 组内最小样本量，避免只为拟合训练数据切出很小组。
- 早测失败/重测代价与延后风险的明确表达。
- 边界和时点在重采样、检测误差扰动下的稳定性。
- 外部适用范围：题面地区样本大多为高 BMI，不应直接外推所有人群。

**竞赛中的时点或异常判定只用于题目分析，不构成实际医疗建议。**

### 8.6 排队与公平：2019 C 的扩展准备

了解到达率、服务率、等待时间、队列长度及 Little 定律 $L=\lambda W$ 的适用条件；统一“系统内”还是“仅排队”的统计边界。

M/M/1、M/M/c 依赖相应到达、服务与稳定性条件。航班集中到达、分批放行和多上车点可能更适合离散事件仿真。

公平也必须定义：收益方差、低分位收益、单位时间收益差距还是其他指标。不能只写“兼顾公平”，却没有可以计算和比较的量。

## 9. 把方法变成可解释、可检验的论证

### 9.1 假设要附“理由与后果”

建议使用：

| 假设 | 依据 | 作用 | 可能偏差 | 如何检查 |
|---|---|---|---|---|
| 短期内某损耗机制稳定 | 数据时间范围、业务背景 | 降低参数维度 | 季节变化可能使估计失效 | 分时段估计、改变参数比较 |

禁止用假设抹掉题目明确要求。例如题目要求考虑不确定性，就不能在最终方案中仅写“假设所有参数确定不变”。

### 9.2 验证设计应在建模前写出

每个模型至少有三类证据：

1. **结构正确性：** 单位、约束、守恒和逻辑。
2. **数据支持：** 留出误差、残差、分组对照或其他适当检验。
3. **结论稳定性：** 参数、样本或模型设定变化后的表现。

如果想不出如何证明“这模型比简单方法更好”，应该先重新明确目标，而不是先加复杂度。

### 9.3 如何写“模型创新”

优先写具体贡献，例如：

- 按采血事件区分技术重复和纵向测量，减少伪重复。
- 在不同材料间统一产出当量，修正只比较采购单价的偏差。
- 显式加入历史轮作状态，避免跨年度约束遗漏。
- 以决策收益而不是单一预测误差选择模型。

不要把调用现成库、替换算法名称或加一层权重直接称为创新。

### 9.4 与队友的交接标准

建模手给编程手：变量、公式、单位、边界、信息时点、小算例、输出和检验。

建模手给论文手：选择理由、参数来源、主要结论、证据和局限，而不是只给公式截图。

每次结构修改必须同步模型版本；不能论文已定稿、代码仍在使用旧约束。

## 10. 八周系统训练计划

建议每周安排若干固定学习时段，约 12—18 小时用于平时学习与练习；整题限时模拟另计。若基础薄弱，应延长周期，而不是减少验收。不要把每周计划理解为必须把该主题所有理论学完。

| 周次 | 建模手重点 | 与编程手共同产出 | 本周验收 |
|---|---|---|---|
| 第 1 周 | 读题、粒度、数据口径、统计基础 | 2022 或 2023 的数据字典、审计报告 | 能解释每列含义、主键、缺失与单位 |
| 第 2 周 | 相关、回归、基本检验、区间 | 一个回归基线、残差图、推断说明 | 能解释系数，不把相关当因果 |
| 第 3 周 | 分类、聚类、评价与验证 | 2022 的分类/亚类分析与稳定性表 | 能说明为何这样切分和选择指标 |
| 第 4 周 | 时间规律、预测与需求关系 | 2023 的日汇总和滚动预测对照 | 没有未来信息泄漏；优劣有基线 |
| 第 5 周 | LP、MILP、逻辑与库存约束 | 2021 的缩小版订购—运输模型 | 手算/枚举一致，约束审计通过 |
| 第 6 周 | 多期、不确定性、风险 | 2024 的缩小版轮作与情景模型 | 明确历史状态和信息时点，无预知未来 |
| 第 7 周 | 将分析、预测和优化串起来 | 以 2023 等题做 24—36 小时阶段模拟 | 每问有结果和检验，完成论文主体草稿 |
| 第 8 周 | 完整模拟与复盘 | 选未完整做过的题，按正式时长交付 | 全流程重跑、论文与结果一致、提交演练 |

每周固定复盘三件事：本周最严重错误是什么；哪种复杂方法没有收益；下次如何用检查提前发现。

### 如果只有两周

- 第 1—2 天：数据字典、描述统计、模型任务卡。
- 第 3—4 天：回归、分类基线和验证切分。
- 第 5—6 天：线性/整数规划与约束表达。
- 第 7 天：时间预测基线、敏感性和不确定性基本方法。
- 第 8—10 天：与队友完成一题的主要问题并写出结果。
- 第 11—14 天：完整演练关键链路、复盘和整理工具卡；按可用时间安排正式时长模拟。

取舍：保留统计、验证、优化主干，暂时不学深度学习和多种启发式算法。

### 如果只剩两天

这时不可能系统补齐全部能力。应以降低失败风险为目标：

**第一天：** 读当前规则；和队友拆一份真题；确定掌握最好的回归/分类基线与规划工具；手工检查一个完整小例子。

**第二天：** 演练“任务卡→数据→模型→结果→论文一小节→支撑材料”；整理假设卡、符号表、验证清单；明确分工与休息安排。

停止追新算法和猜题。不会的方法标记为风险，不靠临时粘贴代码伪装掌握。

## 11. 真题怎样练，才能把知识变成能力

### 11.1 推荐顺序

| 阶段 | 推荐题目 | 重点训练 | 不要跳过的交付 |
|---|---|---|---|
| 入门分析 | 2022 C 的部分问题 | 表格理解、关系分析、分类与亚类 | 数据审计、验证与敏感性 |
| 预测与决策连接 | 2023 C | 多表、时序、需求—价格—补货 | 固定截止时点回测、利润口径 |
| 运筹基础 | 2021 C | 供应可靠性、库存、运输 | 统一单位、可行性与结果模板 |
| 多期风险 | 2024 C | 轮作、跨年状态、不确定性 | 约束清单、情景外评估 |
| 特殊统计结构 | 2025 C | 重复测量、达标时间、不平衡 | 对象级验证、删失与误差说明 |
| 迁移扩展 | 2020、2019 C | 风险到信贷、排队与公平 | 参数依据、外部数据来源、真实约束 |

入门题“适合练某一部分”不等于整道题简单，例如 2022 的风化前成分恢复本身就有较强假设和可识别性问题。

### 11.2 一道题做三遍

**第一遍：独立做基线。** 不先看优秀论文；读原题、写任务卡、做出最小完整解答。

**第二遍：比较不同思路。** 赛前选择 2—3 篇同题论文，比较假设、模型结构、检验和失效点，而不是只抄算法名字。

**第三遍：限时重做。** 从原始数据开始，使用自己的模板重跑并写清楚结果。记录比第一遍快在哪里、哪些错误被消除。

优秀论文是可学习的案例，不是无误的标准答案。能指出并验证其假设边界，比照搬结构更有价值。

### 11.3 阅读优秀论文的六栏笔记

```text
本问实际要求：
作者最关键的假设与简化：
数据转成参数的方法：
核心模型与约束：
验证证据及可能缺口：
我会保留、修改或拒绝的部分：
```

仓库已有 2020—2024 年优秀论文可用于此类赛前对照；不要推定尚未检查的年份也有对应优秀论文。

## 12. 建模手应提前准备的资料包

不是收集几百个算法文件，而是准备少量经过训练验证的资料。

### 12.1 方法卡

每种常用方法一页，包含：适用任务、假设、公式、输入输出、评价方式、典型失败、可运行示例位置、原始文献或官方文档。

优先卡片：

1. 线性回归与残差诊断。
2. 逻辑回归与分类阈值。
3. 分组/时间验证与泄漏检查。
4. 线性规划、0-1 逻辑、库存平衡。
5. 预测基线与滚动回测。
6. 敏感性、情景和 Bootstrap。
7. 聚类与综合评价的使用边界。
8. 重复测量/成分数据/删失等专项提醒。

### 12.2 四张可复制模板

- **任务卡：** 输入、输出、粒度、信息时点、约束、基线、检验。
- **假设卡：** 假设、依据、作用、偏差、验证。
- **模型卡：** 变量、参数、公式、求解、输出、局限。
- **结果卡：** 运行版本、主要数字、图表、证据、结论边界。

### 12.3 错题本比新资料更值得维护

重点记录：

- 把百分数当小数、把不同单位直接相加。
- 把记录数当独立样本量。
- 在全数据上标准化或筛选特征后再验证。
- 销量直接当需求、信用等级直接当违约概率。
- 漏掉初始状态、轮作或最低采购量。
- 用超时解冒充最优解。
- 用相同数据反复调整阈值，再称其为最终测试。

每条都配一个能触发错误的最小反例和检查办法。

## 13. 上场前的能力验收与合规

以下为自测标准，不是官方参赛门槛。

### 13.1 能力自测

- [ ] 拿到新题后，能在一小时左右给出逐问任务卡与数据关系，不急着报算法名。
- [ ] 能写出一个采购/种植问题的变量、目标和主要约束。
- [ ] 能解释什么时候应按时间、企业、文物或孕妇划分验证集。
- [ ] 能指出一个高准确率模型可能存在的泄漏或不平衡问题。
- [ ] 能区分评分、概率、预测和因果结论。
- [ ] 能给每问设计至少一个基线、一个有效检验和一个局限说明。
- [ ] 能用手算小例子检查目标与约束。
- [ ] 能向队友解释求解状态、最优性边界和风险假设。
- [ ] 能读懂核心代码，确认它与数学模型一致。
- [ ] 能在结果卡上找到论文每个关键数字的来源。

### 13.2 2026 年合规准备

依据当前规则：[规]

- 赛前与老师、同学交流训练方法；赛中不能接受队外对赛题的指导与讨论。
- 赛中不浏览当届解题讨论、直播、相关交流平台内容，也不公开上传讨论和代码。
- 公开资料必须规范引用，不大篇幅照搬。
- 使用 AI 时，由本队主导核心建模并逐项核验；保留使用环节、工具版本、采纳修改和核验记录。
- 无论是否使用 AI，都在论文参考文献前作相应声明；实际使用时提交 `AI 工具使用详情.pdf`。
- 不让 AI 替你虚构参数依据、文献、检验结论或算出的数字。

**建模手的最终目标不是“我知道很多模型”，而是“我能说明为什么这样建、如何算、凭什么信”。**
