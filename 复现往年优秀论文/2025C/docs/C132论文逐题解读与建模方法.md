# C132论文逐题解读与建模方法

这篇论文的主线，是把同一份检测数据逐步转换成四类数学对象：重复测量回归数据、个体达标时间、个体生存概率曲线和染色体异常类别。学习时先辨认每一步预测的对象，再看模型名称，能更容易理解其选型理由和局限。

具体实现差异见 [复现说明](复现说明.md)，代码与结果入口见 [README](../README.md)。下述解释以当前可运行实现为基础，凡是补充内容会明确指出。

## 1. 先理解数据：一条记录不等于一位孕妇

附件有1082条男胎记录，但仅267位男胎孕妇；605条女胎记录来自147位孕妇。一次采血可能多次检测，同一孕妇也可能有多次采血。

这个层次结构决定了三件事：第一问不能默认1082条记录互相独立；第二、三问的分组单位应是孕妇；第四问评价新孕妇时，必须把同一人的所有记录分在同一侧。

另一个关键区别是 **AB列的非整倍体判定** 与 **出生后健康结局**。题目第四问明确要求前者作为标签。出生后不健康可能有其他原因，AB异常也不是等同于所有出生疾病；两者混用会改变问题。

建议先运行 [00_preprocess.py](../scripts_tables/00_preprocess.py)，查看 [数据审计](../outputs/tables/00_数据审计.csv) 和 [孕妇汇总](../outputs/tables/00_男胎孕妇汇总.csv)。重点看记录数、孕妇数、同孕周记录、第一次与最后一次孕周，以及删失类型。

## 2. 问题一：Y浓度和孕周、BMI有什么关系

### 2.1 从Pearson开始，为什么还需要LMM

Pearson系数描述两个变量的线性共同变化：

\[
r_{XY}=\frac{\sum_i(X_i-\bar X)(Y_i-\bar Y)}
{\sqrt{\sum_i(X_i-\bar X)^2\sum_i(Y_i-\bar Y)^2}}.
\]

它适合做探索图、发现BMI与体重共线性，但未控制其他变量，也没有解决重复测量的依赖。记录层的普通Pearson p值不能取代最终模型检验。

假设两位孕妇同样在16周检测，一人的Y浓度一直较高，另一人一直较低。这种稳定的个体差异可以用随机截距 \(u_i\) 表示：

\[
Y_{ij}=\underbrace{\beta_0+\beta_t t_{ij}+\beta_{t^2}t_{ij}^2
+\beta_h H_{z,i}+\beta_b BMI_{ij}}_{\text{总体固定效应}}
+\underbrace{u_i}_{\text{孕妇个体偏移}}+\epsilon_{ij}.
\]

其中 \(u_i\sim N(0,\tau^2)\)，\(\epsilon_{ij}\sim N(0,\sigma^2)\)。同一个人的记录共享 \(u_i\)，自然形成相关性。

### 2.2 为什么放入孕周平方

浓度随孕周可能不是匀速增长。线性项和平方项共同给出导数：

\[
\frac{\partial E[Y]}{\partial t}=\beta_t+2\beta_{t^2}t.
\]

本次系数约为 \(\beta_t=-0.003014\)、\(\beta_{t^2}=0.0001701\)，转折点约8.86周。样本孕周位于转折点右侧，因此观测范围内表现为随孕周上升且增长速度增加。不能只看到线性项为负就说“孕周越大Y越低”。

BMI每增加1，调整其他项后的Y比例平均约降低0.001354，即 **0.1354个百分点**。身高标准分每增加1，约降低0.003833，即0.3833个百分点。这里是百分点，不是相对下降百分之多少，也不意味着所有个体都按这个斜率变化。

### 2.3 怎样判断模型有没有必要

- **联合Wald检验**：检验四个非截距固定效应是否同时为零。
- **ML似然比检验**：比较包含随机截距与无随机截距的模型。
- **AIC/BIC**：在拟合改善与参数复杂度之间平衡。
- **ICC**：\(\tau^2/(\tau^2+\sigma^2)\)，本次约0.743，表示模型中约74.3%的残余变异结构来自个体间差异。
- **诊断图**：检查随机截距尾部、条件残差随拟合值的分散程度和LOWESS趋势。图形支持某个近似假设，不是证明该假设绝对成立。

代码：[mixed.py](../scripts_tables/mixed.py)。重点结果：[固定效应与表1对照](../outputs/tables/12_固定效应与论文表1对照.csv)、[模型检验](../outputs/tables/13_模型检验.csv)。

## 3. 问题二：如何根据BMI安排检测时点

### 3.1 两阶段结构

论文把问题拆成：

1. 每位孕妇估计一个最早达标时间 \(T_i\)。
2. 在BMI轴上分组，为每组选择检测时点，并最小化加权风险。

这是一种常见的“先估计个体需求，再优化群体决策”方法。优点是分工清楚，缺点是第一阶段的不确定性会传入第二阶段。

### 3.2 GPR为什么适合稀疏个体轨迹

每人通常只有几次检测，复杂曲线不能靠大量样本直接拟合。高斯过程给函数一个先验：

\[
f(t)\sim GP(m(t),k(t,t')).
\]

RBF核认为相近孕周的函数值更相似，长度尺度控制曲线平滑程度；WhiteKernel描述测量噪声。给定几个观测点，GPR返回每个孕周的预测均值和标准差。

论文用 \(\mu(t)-1.96s(t)\ge0.04\) 找相对保守的模型时间，再用最早实测达标点修正。需要理解：这个修正会覆盖原先的保守下界判断，因此最终 \(T_i\) 并不具有统一的“95%置信”解释。

如果某人第一次测就超过4%，只知道真正达标时间不会晚于这次检测；如果观测期始终没超过4%，只知道达标时间晚于最后观测。这分别是左删失和右删失。GPR给出更早的时间，是借助模型作出的推断。

### 3.3 用分位数选择时点

设某组有5个人，估计时间为 `[10, 11, 12, 16, 20]`。如果希望至少80%已达标，经验逆CDF应取第4个人的16周。默认线性分位数可能落在观测值之间，它与严格的“至少80%”定义不完全一样；当前输出同时列两种口径及实际覆盖率。

目标比例提高通常会推迟同一组的推荐时点，但如果每个目标比例都重新优化分组，成员也在变化，因此“低BMI组”这个名称不代表固定的一批人，其曲线不必严格单调。

### 3.4 风险目标与分组搜索

第一、二阶段分别解决“什么时候可能达标”和“晚检测要付出多大风险”。第二问采用：

\[
\min_{b_1,\ldots,b_{k-1}}\sum_{g=1}^k n_gR_2(Q_p(T_i:i\in G_g)).
\]

每组人数加权，避免只优化组数而忽略人群规模；最小组人数限制避免产生过小、脆弱的组。

遗传算法把BMI分割点看作染色体基因，通过选择、交叉、变异搜索低风险边界。学习时应查看 [GA与DP对照](../outputs/tables/22_GA与动态规划对照.csv)：GA是启发式搜索，不能仅凭一次收敛就证明全局最优。

本问题恰好有连续区间结构，因此动态规划能提供精确参照。阶梯风险函数只关心是否跨过12/27周，许多不同边界可能具有相同风险。论文给出的某一组边界并不一定是唯一合理答案。

### 3.5 怎样理解敏感性

“目标从75%改到90%”是政策偏好变化；“读数加0.2个百分点随机噪声”是测量误差。两个实验回答不同问题。本复现两者都做，并分别报告。

代码：[gpr.py](../scripts_tables/gpr.py)、[optimization.py](../scripts_tables/optimization.py)。结果：[个体达标时间](../outputs/tables/21_个体GPR达标时间.csv)、[BMI策略](../outputs/tables/22_BMI分组策略.csv)、[误差汇总](../outputs/tables/23_读数误差汇总.csv)。

## 4. 问题三：从一个时间变成一条达标概率曲线

### 4.1 生存分析中的“事件”

这里的事件是Y浓度达到4%，生存函数不是孕妇或胎儿死亡概率，而是“到这个孕周还没达到浓度阈值”的概率：

\[
S_i(t)=P(T_i>t\mid X_i),\qquad F_i(t)=1-S_i(t).
\]

因此 \(F_i(t)\) 越大，表示截至该孕周已经达标的模型概率越大。

### 4.2 混合网络怎样分工

| 部分 | 输入 | 作用 |
|---|---|---|
| MLP | 年龄、身高、初始体重、初始BMI | 学习静态生理量的非线性和交互 |
| LSTM | 变长的孕周—Y序列 | 编码已有检测轨迹 |
| 融合层 | 两个16维表示 | 合并静态与动态信息 |
| DeepHit型输出头 | 融合表示 | 给出离散事件时间PMF和尾部概率 |

PMF \(p_i(s)\) 累加得到 \(F_i(t)=\sum_{s\le t}p_i(s)\)。某人的CDF到40周仍小于目标，应该报告模型没有达到目标，不能强行写成40周达标。

不同人序列长度不同，需要填充成矩阵。但填充值不是检测结果：本实现通过有效长度打包LSTM，取最后一个真实时间步的状态，避免网络学习人为的零填充。

### 4.3 损失为什么必须处理删失

精确事件时间已知时，用 \(-\log p_i(T_i)\)；只知道到 \(C_i\) 还没发生时，用 \(-\log S_i(C_i)\)。

若只知道事件发生于 \((L_i,U_i]\)，则应利用整个区间：

\[
-\log\{F_i(U_i)-F_i(L_i)\}.
\]

对首次观测就达标的人，左端可以是计算域前；对始终不达标的人保留右尾。丢弃未达标者容易让总体推荐时间偏早。

排序损失让已较早达标的人在对应时间具有更高累计概率。但实测区间重叠时，先后顺序不一定可知，所以本包的静态区间对照不对这些人强行排序。

### 4.4 本题最容易忽略的信息时间

如果模型输入已经含有20周测到的Y浓度，再用它预测该孕妇12周是否达标，就使用了决策时未来才知道的信息。即使训练与测试孕妇不同，这个用途问题仍然存在。

本复现因此给出两种结果：完整轨迹的 `paper_history` 用于回顾性方法复现；不含Y轨迹的 `static_interval` 用于检查仅凭基线信息能学到多少。后者也不是已经验证的临床方案，首次登记的BMI、体重和实际决策时间仍需在真实场景中一致。

### 4.5 概率曲线怎样进入BMI分组

每组先平均个体CDF：

\[
\bar F_g(t)=\frac1{n_g}\sum_{i\in G_g}F_i(t),\qquad
 t_g(p)=\inf\{t:\bar F_g(t)\ge p\}.
\]

这个平均值表示组内预期达标比例，不是要求每个人都至少有p的达标概率。得到组时点后，再套入风险函数和GA/DP分组流程。

代码：[survival.py](../scripts_tables/survival.py)。结果：[生存评估](../outputs/tables/31_生存模型评估.csv)、[个体CDF](../outputs/tables/31_个体达标概率.csv)、[分组策略](../outputs/tables/32_BMI分组策略.csv)。

## 5. 问题四：女胎异常判定与堆叠学习

### 5.1 为什么要先训练专家

T13、T18、T21和复合异常可能有不同的特征组合。四个专家将23项检测、生理指标转换为4个概率，可以看成四个针对不同目标的中间判断。

元模型再接收这4个概率，以及年龄、BMI和三个染色体Z值，学习各专家之间的互补关系。元模型预测具体异常组合，随后把“无异常”与“任一异常”合并，得到二分类结果。

### 5.2 OOF元特征是什么

元模型训练时不能直接使用专家在自己训练数据上的预测。如果专家已经记住样本，这些概率会过分乐观，元模型在真正新数据上就遇到完全不同的输入分布。

正确做法是：内层每次拿一部分孕妇训练专家，预测其余孕妇；把所有折的未见样本概率拼成OOF矩阵，再用这张矩阵训练元模型。

整个过程还要包在外层孕妇分组验证里。外层测试孕妇不参加专家调参、OOF构造、填补估计或元模型训练；这样外层预测才有资格用于最终评价。

### 5.3 稀有类别与准确率陷阱

女胎605条记录中有538条AB正常，异常67条。把每条都预测正常，准确率就有 \(538/605\approx88.93\%\)，但异常召回率是0。

因此本包同时报告：

- 异常召回率：67条异常中检测出了多少；
- 精确率：预测异常的记录中有多少真实异常；
- 平衡准确率：让正常与异常两类的召回权重相同；
- ROC-AUC、PR曲线和平均精确率：检查概率排序，而非只看一个固定判定点；
- 每种具体异常的支持数、召回和F1：避免大类掩盖极小类。

当前堆叠模型只检测出3条异常，漏检64条，结果说明在当前原始数据、特征和分组验证下，该方案尚不足以可靠检出异常。不能为了复刻论文高分而换成包含测试孕妇的训练集。

### 5.4 Z规则如何评价

正文用Z≥3的组合规则修正部分稀有复合异常。规则是一项需要评估的模型组成，不能从阈值定义直接推出零漏诊。在当前OOF结果中，该规则前后指标相同；结果表保留两套预测以供核对。

代码：[classification.py](../scripts_tables/classification.py)。结果：[逐记录OOF预测](../outputs/tables/42_女胎逐记录OOF预测.csv)、[混淆矩阵](../outputs/tables/42_混淆矩阵.csv)、[总体指标](../outputs/tables/42_总体与分折指标.csv)。

## 6. 建议的学习顺序

1. 从预处理和第一问入手，弄清楚一条记录、一位孕妇、固定效应和随机效应。
2. 手算一个小组的分位数与风险，再看GPR输出如何影响分组结果。
3. 用8个人的例子穷举所有BMI分割点，对照动态规划，理解GA收敛与全局最优的区别。
4. 再学习PMF、CDF、右删失和区间删失；先能手算损失，再阅读神经网络代码。
5. 最后检查第四问的数据划分和OOF流程，先确认评估可信，再讨论模型是否足够复杂。

建议把“模型结构复现成功”和“论文全部数值与结论得到验证”分开记录。本项目第一问接近逐值核对，其余各问提供可运行的方法重建、真实差异和补充验证。
