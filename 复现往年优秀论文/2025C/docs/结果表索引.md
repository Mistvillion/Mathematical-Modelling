# 结果表索引

Excel提供同一批CSV的集中浏览版；中文文件名说明内容，内部英文字段对应代码变量。概率采用0—1比例，孕周采用周；`inf`表示模型未得到有限达标时间。

`target`为目标达标百分比；`n`是孕妇数，`n_records`是检测记录数；`solver`区分GA与DP。
`paper_history`是完整轨迹GPR伪标签回顾性重构；`static_interval`是基线静态信息和实测区间删失对照。
`feasible`表示10—40周计算域内可达，`within_10_25_weeks`单独标记常用检测窗口。
