## 2. 闭合、零值与对数比

闭合：`C(x)=100*x/sum(x)`。原文附录D用每行**非零成分**的几何均值取对数比，零位置填0。本包 `paper_clr()` 实现相同数值逻辑，但使用对数均值避免连乘溢出。

这不是在固定14维正单纯形上的标准CLR，因为各行非零集合不同。也不能把原始未检出的0和“恰好等于几何均值、因而对数比为0”的坐标混为一谈。比如原始成分(50,50,0)变换后为(0,0,0)，前两位仍真实存在。

因此可运行逆变换 `inverse_clr(z, present)`（见 [composition.py](../scripts_tables/composition.py)）使用独立的原始非零掩码 `present`，在掩码内做稳定softmax，再闭合为100%。作者以 `z==0` 判断缺失的代码见论文附录C，当前目录未保留单独的附录转录文件。

另外导出 `replaced_clr` 对照：先闭合到1，每个零替换为`delta=1e-4`，其余比例按`1-零数*delta`缩减，再做标准CLR。它仅用于展示另一种零处理方式，**没有暗中替换论文主计算链**。检出限未知，不能认为此delta具有唯一正确性；也未以此对所有下游模型作完整敏感性研究。

论文表6/7虽然写Yates校正，数值却与前面的未校正Pearson相同；本包不把其标签照抄成修正后的统计方法。p≥0.05只写“未发现充分关联证据”。

## 4. 问题1.3：能复现分组和回归，不等于能证明预测

Ward采用原始含量、欧氏距离、不标准化。附录B先切为两类，再在每类中二分；本包实现这个过程，并将计算分区与表11/12比较。两种玻璃的二类、四类ARI均为1；只是成员分区一致，类别编号本身没有时间意义。

**高钾表11与表13的第3、4组互换。** 按表11名单计算的SiO₂中心为3.175855、3.068639、4.187045、3.385352；表13的后两项顺序则相反。只有采用表13顺序，才能得到表15的拟合：

```text
高钾 SiO2： 0.227227*t² - 0.801107*t + 3.752787，R²=0.999757
铅钡 SiO2：-0.339597*t² + 1.070458*t + 2.322306，R²=0.883789
```

因此默认拟合与28张拟合图按**表13/14中心顺序**生成；CSV保留原名单阶段和实际拟合阶段两列。按表11/12原顺序的整套回归另导出为 [13_按表11_12名单顺序回归_对照.csv](../outputs/tables/13_按表11_12名单顺序回归_对照.csv)。每种成分用4个组中心等权二次最小二乘，不按组样本数加权。

对每个风化点，设其log-ratio坐标为z、实际拟合阶段为t、拟合函数为f：

```text
shift：       z0 = f(1) + [z - f(t)]
signed_sqrt： z0 = f(1) + sign[z - f(t)] * sqrt(abs[z - f(t)])
```

默认 `signed_sqrt` 保留作者“残差开平方后平移”的思路，修正为实数运算，并使用实际阶段t。它**不是原附录根式的代数等价改写**。`shift` 是不作开方收缩的平移对照；两套预测都导出。

按原附录跳过高钾Na₂O/SnO₂/SO₂和铅钡K₂O/MgO的坐标更新；注意跳过的是变换坐标，逆变换闭合后该成分的百分含量仍可能变化。不能把这解释为“绝对含量保持不变”。

两套输出均有38点、非负实数、每行和为100%。零位按检测掩码保留，意味着**不能恢复已经流失到未检出的成分**，这也是07等点与表17差别较大的原因之一。这只是清楚定义的一套补写假设，不能称为已证明更准确的化学恢复。

附录A的平均联接混合聚类也重新计算，并用`*`标记本包预测。它可检查预测是否接近某组，却不能替代真实风化前数据的外部验证。

## 5. 问题2.1与3：规则、重训树、聚类对照

论文固定规则应用于**原始PbO百分含量**，不把阈值套到CLR或闭合后百分比：无风化≤8.495%为高钾；风化≤6.155%为高钾；其余为铅钡。图4/5是这两个规则的重绘。

另有两种重训模型：

- 预选PbO：特征来自论文决定，重新学习阈值。用全部已知数据训练后，本次阈值为无风化6.965%、风化5.150%，并非8.495/6.155。
- 全14成分：熵准则二叉树自由选特征。本次无风化组选择K₂O、风化组选择SiO₂。sklearn的连续特征二叉树不等于原文纯ID3实现，也不能保证与SPSSPRO打破并列最优特征的规则一致。

两者都导出70%/30%分层采样点划分的评估，也导出按文物编号分组的5折验证。每一折的训练/测试文物不重叠，划分名单另存CSV。**它仍以论文预先定义的风化组为条件，没有在每一折内重新估计风化聚类和阶段，不能称为整个建模流程完全无泄漏的嵌套验证。**

本次预选PbO的风化组5折中有1折准确率0.875，其余1.0；“全部指标恒为1”并非不变结论。表单3本次结果见 [outputs/运行结果.md](../outputs/运行结果.md)：

- 固定PbO规则与预选PbO重训树均得到A1/A6/A7高钾，其余铅钡，与论文表26一致。
- 全14成分重训树对A1、A5与论文规则不同。
- 原始含量Ward对照对A5给出高钾，与论文表27不同。

未知聚类通过已知样本多数标签命名簇，不使用未知标签参与命名。它是另一种模型对照，不是交叉验证，更不是未知真值。

未知敏感性同时独立乘性扰动14种原始含量，幅度为0/5%/10%/20%/50%/100%，默认每场景200次，固定种子；不重新闭合，以保持模型输入和阈值单位一致。它检验的是数值输入扰动，不是完整的成分约束测量误差模型。

0乘任何比例仍为0，因而“零PbO很稳定”只适用于此扰动方式。结果另报到阈值的绝对百分点距离；这有助于看清零值对加性误差并非无限稳定。边界距离/相对幅度是到达阈值的距离，等号仍归高钾；高钾跨界需要严格超过它。

## 6. 问题2.2：亚类与敏感性

原文表21星号和表25在高钾未风化代表变量处不完全一致，本包以明确列出扰动变量的表25为准：

| 四大组 | 主分析使用的代表成分 |
|---|---|
| 高钾无风化 | SnO₂、CuO、CaO |
| 铅钡无风化 | Na₂O、CuO、SiO₂ |
| 高钾风化 | SnO₂、CuO、SO₂ |
| 铅钡风化 | Al₂O₃、CuO、SrO |

R型重算采用原始含量的Pearson距离`1-|r|`和最短距离法，恒定列排除；尽可能切成3类。由于作者没有给可执行的“代表性”选择规则，本包另做确定性对照：每类选择到同类其他成分总距离最小的成分，按附件顺序处理并列。

Q型主结果用表25的代表成分、原始含量、不标准化、Ward、每组k=2；自动R代表的Q型结果另存对照。**自动R分组与表25代表特征并未强行拼接成同一条已被验证的选择链。** 原文图7的部分成员与本次不同，因此图7重绘使用本次实际成员并标注来源。

合理性输出包括轮廓系数、主结果/自动代表结果的ARI。默认每个代表成分分别在±5/10/15/20%下做200次扰动，重新聚类，用不受簇编号互换影响的ARI比较。输出最小ARI、平均ARI、完全一致比例。随机种子由整套试验顺序共同决定，结果对应同一完整运行。

本次在论文列出的扰动范围内，铅钡无风化SiO₂±5%的完全一致比例为0.790，高钾风化CuO±15%为0.935。它们是**本包输入空间和参数下**的结果，不能反过来伪称已找到作者原程序的同样结果，但足以说明不可盲信未给参数与次数的“任意扰动都不变”。

## 7. 问题4与图表范围

原始非负含量按列除以其均值，ρ=0.5；每一成分分别作为母序列。对该母序列所有其他有效成分与所有采样点的绝对差，求两极最小差和最大差，再计算关联系数，并对采样点等权平均为关联度。全零列不能均值无量纲，保留NaN并明确排除。

每个母序列的极差归一化尺度可能不同，因此最终关联度矩阵不强制对称；它不是Pearson相关矩阵。行序只是附件采样顺序，不代表时间。

原文没有完整SPSSPRO输入、权重和操作记录；本包选择等权、明确空间，不使用有负数且均值可能接近0的CLR做均值除法。表28逐项差值单独导出，**没有把0.893等论文参考数值填入计算矩阵，也没有为了“接近1”调参数**。

图表共91个独立文件：正文图1–9拆成19张；附录A两张；附录B另含4张二次分支聚类图和28张回归图；其余母序列26张；R/Q聚类及重训树12张。全部映射见 [图表索引.md](图表索引.md)。原图布局、颜色与SPSSPRO交互滑条不逐像素仿制；每张数据图来自代码重算。
