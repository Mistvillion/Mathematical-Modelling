# 我对 C155 这篇论文的评价

**它适合学习“怎样把四问组织成一篇完整建模论文”，但不适合不加判断地当作统计与预测的标准答案。** 成分数据意识、可解释分类和结果组织是亮点；风化前预测的科学依据、统计推断措辞和可复现性则明显不足。作为训练材料，我建议一边读，一边对照运行结果审查它的论证。

这次评价不是只看摘要：已通读41页扫描件，核对题目采样说明、原始附件、附录B/C/D，并实际重算主要步骤。这里区分“论文明确存在的问题”与“本次补写因参数不同出现的差异”。

## 最值得学的地方

**第一，识别到了成分数据的特殊性（p4–5）。** 各成分比例受总和约束，直接把14列当成普通独立数值变量会有问题。主动做闭合、讨论对数比空间，是这篇论文最有价值的建模意识。虽然零值实现不够严谨，但这个出发点值得学。

**第二，分类规则很容易解释（p18–20）。** 用PbO区分高钾/铅钡，既能写成简单的决策规则，也能联系助熔剂和玻璃类型背景。相较于只给一个黑箱分类分数，这样的结果更容易供考古人员理解。需要注意，8.495与6.155是样本/训练设定下的阈值，不是自然界中固定的两条界线。

**第三，四问衔接和输出意识不错。** 从数据清洗、分组描述，到分类、亚类、未知样本鉴别，再到关联分析，读者基本能跟上；箱线图、聚类树、决策规则和敏感性表也都有明确用途。备赛时值得学习这种“每一问都有具体结果”的写作习惯。

## 需要认真警惕的地方

| 原文位置 | 问题 | 为什么影响可信度 |
|---|---|---|
| p5、p38–41 | 空白补0后只对非零子组成取对数比；逆变换用坐标是否为0识别未检出 | 不同样本使用不同非零集合；真正等于几何均值的成分也会变成0，可能被误删。不能直接当作标准CLR处理 |
| p6–8 | 对2×3、2×8稀疏列联表泛用Yates表述；“未显著”写成“独立不相关” | Yates连续性校正不是处理任意稀疏表的通用办法；不能拒绝独立假设不等于证明独立 |
| p8–10 | 对变换后有正负值的坐标计算CV；偏度方向与“哪边数据更多”的解释也不严谨 | CLR不是适合用标准差/均值作相对离散度比较的比例尺度；尾部方向不等于样本多数所在方向 |
| p11–16 | 用不同文物的聚类组构造“未风化、轻度、中度、严重”的时间顺序 | 横截面组间差异也可能来自原料、产地、埋藏环境和取样差异；聚类本身不能证明是同一风化轨迹 |
| p13–15 | 高钾表11名单与表13中心的第3/4组顺序相反 | 会直接改变回归系数。本次只有交换这两组，才得到表15的SiO₂拟合式 |
| p15–18 | 4个中心拟合二次曲线；低R²就判断不受风化影响；用混合聚类论证预测有效 | 高R²可能只是自由度很少；低R²也可能表示模型错设或噪声大；预测更接近目标组不是外部准确性验证 |
| p19、p24–25 | 少量数据上指标全1，缺少可追溯的划分种子与充分外部验证 | 一些特征在已知样本上同样能完美分离，却会对未知样本给出不同结果 |
| p23–25 | 没有给敏感性随机次数和完整参数，却声称一定范围“无论抽取何数”都不改变分类 | 有限随机实验只能支持经验稳定性，不能证明连续扰动范围内的全称命题；零值的乘性扰动还会天然不变 |
| p25–29 | 将灰色关联度当作很强的“相关”解释 | 灰色关联是依赖无量纲方法、分辨系数和比较尺度的形状相似度，不能直接读成Pearson相关，更不是因果 |
| p32–41 | 附录缺读数据函数、中间Excel、评估函数，部分代码还存在维度/阶段/根式疑点 | 第三方无法只凭PDF直接得到全部图表；“附了代码”不等于“可复现” |

还有两处值得培养审稿敏感度：p11与p12对高钾SiO₂随风化变化的方向表述不一致；p24把表单3解释成与随机采样不同的整体文物比例，超出了题目明示的信息。遇到这类连接前后推理的句子，要回到题目而不是默认接受。

## 实际重算带来的证据

**可核对的结果不少。** 剔除15、17正确；三个Pearson p值分别约0.008715、0.083888、0.506650，与正文舍入值一致；Ward二分与分支内再二分得到的成员分区也能一致。说明基础数据和若干算法步骤有可追溯性。

**回归阶段矛盾可以被数值定位。** 高钾SiO₂按表11名单顺序拟合的二次项约−0.173619；按表13中心顺序则约+0.227227，后者才对应表15。阶段顺序不是一个不会影响结果的小排版问题。

**“已知样本100%”确实不保证未知预测一致。** 本次按全部14成分重训时，无风化组自动选择K₂O、风化组选择SiO₂，已知样本评估仍很好，但A1、A5与论文PbO规则不同。按原文预选PbO后，A1/A6/A7高钾、其余铅钡，能与论文表26一致。由于表单3没有公布真值，这里只能指出方法分歧，不能宣称某一列已被证明正确。

**敏感性结论依赖细节。** 本包按明确记录的原始百分比、Ward、表25代表变量重算，铅钡未风化SiO₂±5%时，200次中完全保持原划分的比例是79%；高钾风化CuO±15%时为93.5%。这不等于复原了作者未公开的所有参数，但也说明不能直接照搬其“范围内任意扰动都不变”的说法。

**灰色关联的原表数值没有被重现。** 本包按非负原始含量均值无量纲、ρ=0.5、等权计算，结果与表28有明显差异，已经逐项导出。没有充足证据时，应报告差异，不能调参数或抄表把它“复现成功”。

## 如果作为备赛范文，我会这样使用

1. 学它如何交代数据性质、组织四问、选择可解释的输出。
2. 自己重做列联检验和组成变换，明确零值、采样层级和统计单位。
3. 把风化前预测降格为“假设情景下的恢复估计”，讨论配对数据缺失、模型不确定性和未检出成分能否恢复。
4. 比较PbO、其他可分特征和不同划分方式；同件文物的多个采样点尽量放在同一验证折里。
5. 敏感性写清变量、幅度、噪声分布、重复次数、种子和评价量；用ARI比较聚类，避免类编号交换造成假变化。
6. 提交从原附件开始的一键流程、每张图的脚本、依赖版本和结果清单。

对这篇论文最有价值的学习，不是把里面的每种算法照搬一次，而是理解：**合理的建模出发点、漂亮的图表和很高的拟合分数，还需要一条经得起数据与代码核对的证据链。**
